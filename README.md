# backend_golang

Este es un proyecto backend en Go.

## 📦 Instalación

Clona el repositorio:
```bash
git clone https://github.com/dduenas-niomads/backend_golang.git

# Pasos para compilar Golang

1. ubicarse en la carpeta del proyecto /backend_golang
2. ejecutar: docker-compose build --no-cache
3. ejecutar: docker-compose up -d --remove-orphans
4. ejecutar: docker-compose restart
